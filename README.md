# Employee Salary System

## Overview

This project is a project named Employee Salary Management System developed using C++. The system manages employee records and calculates salary based on allowances and statutory deductions

## Features

- Add and manage employee records
- Display employee information
- Calculate allowances
- Calculate gross salary
- Calculate salary deductions
- Calculate EPF, SOCSO and EIS contributions
- Calculate net salary
- Console-based salary management

## Technologies Used

- C++
- Visual Studio Code

## Concepts Applied

- Structures
- Arrays

- Mathematical calculations
